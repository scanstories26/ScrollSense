# ScrollSense — know every scroll

Counts Instagram Reels and YouTube Shorts, tracks time, and helps you scroll less. 100% offline (no INTERNET permission).

## Screens
Home · Trends (week vs week, busiest time, heatmap) · Goals (limit, streaks, badges) · Focus (friction, intent check, notifications, bedtime guard) · Setup & privacy · Impact · Scroll score · Diagnostics

## Build online
Push to GitHub; the workflow builds the APK. Actions > latest run > Artifacts > Reelect-APK.
